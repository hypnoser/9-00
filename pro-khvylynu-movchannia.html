Про загальнонаціональну хвилину мовчання

Цей сайт створено як стриманий цифровий екран пам’яті, який можна відкрити на особистому пристрої, телевізорі, інформаційному моніторі або вбудувати у власний інтернет-ресурс.

Відкрити хвилину мовчання Перевірити 60-секундний режим

Що це

Указом Президента України №143/2022 від 16 березня 2022 року започатковано щоденну загальнонаціональну хвилину мовчання о 09:00. Вона присвячена пам’яті співвітчизників, які загинули внаслідок збройної агресії Російської Федерації проти України.

Указ передбачає проведення хвилини мовчання у засобах масової інформації, органах влади, закладах освіти та закордонних дипломатичних установах України.

Офіційне першоджерело: Указ Президента України №143/2022 .

Як працює сайт

Годинник постійно показує актуальний час у часовому поясі Europe/Kyiv. Щодня рівно о 09:00 написи й тризуб стають білими, поступово проявляється український прапор, а метроном позначає кожну секунду. На 58-й секунді прапор починає плавно згасати й зникає до завершення хвилини.

Для перевірки не потрібно чекати 09:00: додайте до адреси параметр ?test=1. Тест триває 60 секунд і повністю повторює основний режим.

ТВ І МОНІТОРИ

Як екран або заставка

  1. Відкрийте головну сторінку в Chrome, Edge, Firefox або браузері Smart TV.
  2. Увімкніть повноекранний режим: зазвичай клавіша F11.
  3. Вимкніть автоматичний сон пристрою та системні сповіщення.
  4. Залиште сторінку відкритою: о 09:00 вона активується автоматично.
  5. Заздалегідь перевірте звук за допомогою адреси з ?test=1.
ДЕРЖАВНІ УСТАНОВИ

Інформаційна панель

  1. Використовуйте окремий комп’ютер або медіаплеєр із синхронізованим системним часом.
  2. Додайте адресу сайту до автоматичного запуску браузера після ввімкнення пристрою.
  3. Для керованих пристроїв дозвольте автоматичний звук тільки для домену цього сайту.
  4. Щодня контролюйте живлення, інтернет, гучність і правильність показу часу.

У керованому Chrome IT-адміністратор може використати політику AutoplayAllowlist.

Запуск на GitHub Pages

GitHub Pages безоплатно публікує статичні HTML, CSS і JavaScript-файли з репозиторію. Для цього сайту не потрібна база даних або серверна програма.

Сайт уже розміщено в репозиторії hypnoser/9-00 і доступний за постійною адресою https://hypnoser.github.io/9-00/.

  1. Відкрийте репозиторій. Увійдіть у GitHub і відкрийте hypnoser/9-00.
  2. Розпакуйте архів. Переконайтеся, що index.html лежить у корені, поруч із robots.txt, sitemap.xml, llms.txt і папкою assets.
  3. Завантажте файли. У репозиторії натисніть Add file → Upload files, перетягніть весь вміст розпакованої папки та натисніть Commit changes.
  4. Увімкніть Pages. Відкрийте Settings → Pages. У розділі Build and deployment виберіть Deploy from a branch.
  5. Оберіть джерело. Встановіть гілку main, папку /(root) і натисніть Save.
  6. Дочекайтеся публікації. Через кілька хвилин сайт оновиться за адресою https://hypnoser.github.io/9-00/.
  7. Перевірте роботу. Відкрийте сайт звичайно, а потім адресу https://hypnoser.github.io/9-00/?test=1 для повної хвилинної перевірки.

Коли з’явиться власний домен

  1. У GitHub відкрийте Settings → Pages → Custom domain.
  2. Введіть придбаний домен і збережіть налаштування.
  3. У кабінеті реєстратора домену додайте DNS-записи, які вкаже актуальна документація GitHub.
  4. Після перевірки DNS увімкніть Enforce HTTPS.
  5. Замініть тимчасову адресу в canonical, Open Graph, sitemap, robots і LLMS-файлах на новий домен.

Детальніше: джерело публікації GitHub Pages та підключення власного домену.

SEO та AI-пошук

У комплекті є метадані для пошукових систем, canonical, sitemap, robots.txt, Schema.org/JSON-LD, Open Graph, вебманіфест, а також llms.txt і llms-full.txt для машинного читання змісту сайту.

Пошуковим AI-ботам дозволено знаходити сторінку та використовувати її як джерело з посиланням. Відомі боти, призначені для формування навчальних наборів моделей, заблоковані у robots.txt. Ці правила є технічним сигналом для добросовісних роботів і не замінюють юридичні умови використання.

Для поточної адреси можна окремо додати Google Search Console, Bing Webmaster Tools та аналітику, не змінюючи роботу хвилини мовчання.
